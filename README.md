# Blazor Web App with Identity, PostgreSQL, MudBlazor and Tailwind v4

This is a template Blazor Web App project you can use to get your identity setup with PostgreSQL, snake-case naming convention, MudBlazor component library and Tailwind v4 installed.

### Tech
Blazor, .NET 9.0.4, EF Core 9, Identity, MudBlazor 8, Tailwind 4

### Usage 

From the project directory run the following command in order to make tailwind refresh on edit:
```
npx @tailwindcss/cli -i /wwwroot/css/tailwind-import.css -o ./wwwroot/css/tailwind.css --watch
```
